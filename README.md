# Projet_UE2_3

## Objectif du site web :
Grace a TrustTheRoll nous permettons les utilisateurs de jouer à des jeux disponibles dans des casinos mais directement sur leur ordinateur.
Nous avons donc deux jeux pour l'instant disponibles : une roulette et un blackjack.
Le choix de la mise est laissée libre a l'utilisateur.

## Ce que nous avons mis en place :
Nous avons une page d'accueil de présentation de TrustTheRoll avec les avis laissés par des utilisateurs, vous pouvez à partir de la vous inscrire puis vous connecter et commencer a jouer !
